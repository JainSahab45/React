## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/JainSahab45/React.git
```

Go to any project:

```bash
cd React/passgen
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
